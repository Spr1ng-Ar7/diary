# 《闲碎》个人日记 · 使用说明

一个纯前端、零依赖的个人日记网页。无需安装、无需联网、无需注册，打开就能写。

---

## 一、文件清单

| 文件 / 目录 | 说明 |
| --- | --- |
| `diary.html` | 页面入口，只包含页面结构，双击打开它即可 |
| `css/style.css` | 全部样式（莫兰迪色板、布局、动画、响应式） |
| `js/texts.js` | 心情定义、答案之书与每日一签文案、错题相关文案 |
| `js/storage.js` | 本地存储读写、图片压缩、备份导入导出工具 |
| `js/particles.js` | 过场粒子特效（漂浮微尘、流动光团、流星） |
| `js/app.js` | 日记主逻辑（写作、翻阅、弹窗、附图、备份恢复等） |
| `js/mistakes.js` | 错题本（记录、翻阅、掌握度、随机自测） |
| `js/answers.js` | 答案之书（经典翻答案）与每日一签 |
| `使用说明` | 本文档 |

所有文件都是纯静态的，无任何第三方依赖，也不需要联网。
注意：`diary.html` 必须与 `css/`、`js/` 两个文件夹**保持原来的相对位置**一起移动，否则样式和功能会失效。

---

## 二、如何打开

- **电脑**：双击 `diary.html`，会用默认浏览器打开（推荐 Chrome、Edge、Safari、Firefox 等现代浏览器）。
- **手机**：把文件发到手机（微信文件传输助手、邮件、网盘均可），在手机上选择"用浏览器打开"。
- **不需要**安装软件，也**不需要**启动本地服务器或联网。

## 三、如何分享给他人

把 `diary.html` 连同 `css/`、`js/` 文件夹**一起打包**（保持目录结构）发给对方即可，对方双击 `diary.html` 就能用。

需要注意：**日记内容不会随文件一起发送**。数据保存在每个人自己的浏览器中，对方收到的是一本空白日记本；你写的内容只有你自己的设备和浏览器能看到，天然私密。

---

## 四、功能说明

页面共有四个标签：**写日记 · 翻阅 · 错题本 · 答案之书**。切换标签时会播放约 2.4 秒的全屏过场动画（详见第六节）。

### 1. 写日记（"写日记"标签）

- 页面自动显示当天日期与星期。
- **今日一句**：每天展示一句固定的治愈短句，同一天内每次打开保持不变，第二天自动更换。
- **心情标记**：提供平静、开心、心动、疲惫、烦躁、期待六种心情，分别对应雾蓝、灰豆绿、脏粉、灰紫、陶土、沙色六种莫兰迪色。
- **标题**：可自己填写，最多 40 字；不填则自动截取正文第一行作为标题。
- **正文**：不限字数，右下角实时统计字数。
- **附图**（新）：点击"添图"按钮可附上照片，一篇最多 6 张；图片会自动压缩后存储，不占太多空间。附图后时间线卡片和详情弹窗都会展示图片。编辑日记时可增删图片。
- **保存**：点击"收存"按钮即可保存；保存成功后会出现随机的治愈提示语，并自动清空编辑区，准备写下一篇。若存储失败（如浏览器空间不足），会保留编辑区内容并提示，不会丢失。
- **清空**：点击"清空"可放弃当前正在写的内容。

### 2. 翻阅日记（"翻阅"标签）

- **时间线**：所有日记按时间倒序排列，并按月份自动分组。
- 每张日记卡片显示心情色点、标题、日期、正文摘要与心情标签；若附有图片，还会显示前 3 张缩略图。
- **搜索**：在搜索框输入关键词，可实时筛选标题或正文中包含该词的日记（输入有短暂防抖，打字流畅不卡顿）。
- **心情筛选**：点击"全部 / 平静 / 开心……"等筛选按钮，只看某一种心情的日记。
- 页面顶部显示日记总数，以及筛选或搜索后命中的篇数。

### 3. 阅读、编辑与删除

- 点击任意日记卡片，弹出详情页，展示完整内容、图片、心情与精确到星期、时分的记录时间。
- **编辑**：在详情页点"编辑"，内容（含图片）会带回写作页修改，保存后更新原日记（不会产生新日记）。
- **删除**：在详情页点"删除"，会有二次确认，确认后该篇永久删除。
- 关闭详情：点"合上"、点击弹窗外的暗色区域，或按键盘 Esc 键。

### 4. 错题本（"错题本"标签）——新

错题本分为"记错题"与"错题集"两个子页，用顶部小标签切换。

#### 记错题

- **科目**：可填数学、语文、英语等，也可从下拉建议中选择；不填默认"其他"。
- **题目**：文字记录，也可拍一张题目照片附上。
- **当时的错解**（可不填）：记下当时怎么错的，方便对症下药。
- **正确解析**（可不填）：正确的做法与关键步骤。
- **错因笔记**（可不填）：一句话提醒自己，比如"粗心""概念不清"。
- 点击"收进"保存后自动跳转到错题集。

#### 错题集

- 所有错题按时间倒序排列，每张卡片显示科目、题目首行、笔记摘要、掌握度标签与附图缩略图。
- **搜索**：可按科目、题目、解析或笔记关键词筛选。
- **掌握度筛选**：点击"全部 / 未掌握 / 复习中 / 已掌握"按钮筛选不同阶段的错题。
- 顶部显示错题总数与待攻克数量。
- 点击错题卡片打开详情弹窗，可查看完整题目、错解、解析、笔记与图片，并可直接切换掌握度等级（未掌握 → 复习中 → 已掌握）。

#### 随机自测

- 点击"随机自测"按钮，从"未掌握"和"复习中"的错题里随机抽一道。
- 弹窗先只显示题目（解析默认隐藏），考一考自己。
- 点"看解析"展开完整解析后，出现"还差点"与"已经会了"两个按钮：
  - 选"已经会了"：该题标记为"已掌握"，不再出现在自测池里。
  - 选"还差点"：标记为"复习中"，下次还可能抽到。

### 5. 答案之书（"答案之书"标签）——新

#### 经典答案之书

- 心里默念一个问题，然后轻触（点击）书页。
- 书本会翻开（3D 翻页动画），片刻后浮现一句简短答案，如"是的，没错。""再等等，时机还没到。""顺其自然就好。"等共 49 句。
- 答案随机出现，且尽量不与上一次重复。
- 心有新的疑问时，再轻触一次即可翻出新的答案。

#### 每日一签

- 答案之书下方有"今日一签"区域。
- 点击抽签，会得到一段较长的治愈签文（共 24 条，如"今日宜慢慢吃饭，宜早早上床，宜原谅自己。"）。
- **一天一签**：抽中后当天再打开仍是同一签，第二天才会更新。

### 6. 治愈系细节与过场动画

- 顶部副标题（如"把今天，轻轻收起来"）每 7 秒轻柔轮换一句。
- 切换四个标签时，均会播放约 2.4 秒的全屏过场：
  - 莫兰迪渐变色幕布缓缓铺开再淡去；
  - 画面中有漂浮微尘、呼吸流动的柔光光团与偶发流星，均为实时绘制的粒子效果；
  - 幕布中央显示**一句**随机治愈短句；
  - 幕布完全铺满的瞬间完成页面切换，因此不会看到页面生硬跳变。
- 过场播放期间重复点击不会被重复触发；系统若开启了"减弱动态效果"（无障碍设置），动画会自动缩短为安静的快速版本。

## 五、数据保存在哪里

- 日记保存在浏览器的 **localStorage** 中，键名为 `morandi_diary_entries_v1`。
- 错题保存在同一浏览器的 **localStorage** 中，键名为 `morandi_mistakes_v1`。
- 每日一签的记录键名为 `morandi_daily_sign_v1`。
- 数据**只存在本机、本浏览器内**：不会上传到任何服务器，离线也能正常使用。
- 每篇日记包含：编号、记录时间、标题、正文、心情，以及编辑时更新的修改时间；若附有图片，图片以压缩后的 JPEG dataURL 形式一并存储。
- 每道错题包含：编号、记录时间、科目、题目、错解、解析、笔记、掌握度、修改时间；若附有图片则同上。
- 页面渲染用户输入的文字前会做转义处理，日记与错题内容不会被当作网页代码执行，可放心粘贴任意文字。

### 备份与恢复（新）

页脚提供了"备份"与"恢复"链接：

- **备份**：点击"备份"会下载一个 JSON 文件，内含全部日记与错题数据。请妥善保存这个文件。
- **恢复**：点击"恢复"会弹出文件选择框，选择之前下载的备份 JSON 文件后，会提示确认（恢复会覆盖当前数据），确认后即从备份中恢复所有日记与错题。

建议定期备份，尤其在清理浏览器数据或重装系统之前。

### 数据的独立性

- 同一台电脑上，不同浏览器（如 Chrome 与 Edge）的日记互不可见。
- 把 html 文件发给别人、复制到别的设备，日记内容都不会跟随过去。

### 可能导致日记丢失的操作

- 清理浏览器缓存 / 网站数据时勾选了本地存储；
- 卸载或重装浏览器、重装系统；
- 使用浏览器的"无痕模式"打开（关闭无痕窗口后数据不保留）。

建议：使用页脚的"备份"功能定期导出一份 JSON 文件妥善保存。

## 六、设计与适配

- **视觉风格**：简约留白，莫兰迪低饱和色系，宋体标题搭配无衬线正文，圆角纸感卡片。
- **响应式**：同一页面适配电脑与手机，小屏幕下自动调整字号、间距与按钮布局，触控区域更大。
- **性能**：粒子特效仅在过场播放期间运行，结束后立即停止并释放，不持续占用资源；柔光图案预先生成复用，并对高分屏做了渲染上限控制。搜索输入有防抖处理，大量日记时也不会卡顿。

## 七、技术构成（供了解）

- 纯原生 HTML + CSS + JavaScript，按"结构 / 样式 / 数据文案 / 存储 / 特效 / 主逻辑 / 错题本 / 答案之书"拆分为多个静态文件，**零依赖、零构建**。
- 脚本为普通 script 标签按序加载（非 ES Module），因此通过 `file://` 双击打开也能直接运行。
- 粒子特效使用 Canvas 2D 与 requestAnimationFrame 实现。
- 数据持久化使用浏览器原生 localStorage，JSON 格式存储。
- 图片上传后使用 Canvas 自动压缩（长边不超过 1280px、JPEG 质量 0.82），以控制 localStorage 占用。
- 不使用任何外部字体、图片、CDN 或第三方库。

## 八、常见问题

**问：双击打开是一片空白或样式错乱？**
请确认 `diary.html` 与 `css/`、`js/` 文件夹仍保持原目录结构一起存放（没有只单独拷走 html），并使用较新的现代浏览器打开。

**问：换了电脑还能看到以前的日记吗？**
不能。日记只存在原设备的原浏览器中，文件本身不携带日记数据。请在原设备上用页脚"备份"导出 JSON 文件，在新设备上用"恢复"导入。

**问：可以两个人共用一本日记吗？**
当前版本定位为本地私密日记本，不支持多人同步。如需多设备共享，需要另行增加后端服务或云端存储。

**问：能导出日记吗？**
可以。点击页脚的"备份"链接，会下载包含全部日记与错题的 JSON 文件。如只需单篇文字，仍可在详情页全选复制自行保存。

**问：附的图片会占用很多空间吗？**
图片在上传时已自动压缩（长边 1280px、JPEG 质量 0.82），单张通常几百 KB 以内。但 localStorage 总容量有限（一般 5–10 MB），建议图片适量、篇数过多时及时备份后清理旧篇。

**问：断网能用吗？**
可以，全部资源都在文件内部。
